# Prespecified design and run notes

The source design was copied without scientific parameter changes from the handoff TOML. Calibration used 100,000 sequences at seed 120260906 and a distinct 100,000-sequence holdout at seed 120260907. Every opportunity draws independent plan/action normals and observation/response uniforms before branching. Formal replication r uses Xoshiro seed 220260905+r, shared across lambda conditions, with independent sequences and no shared learner effect. Smoke uses 320260905+r for r=10001:10005.

The 21-point rule integrates the conditional N(0.9 Z0,0.1) initial distribution; state decay occurs at every unobserved opportunity. The generated response at R=0 is stored as -1, never used as an outcome. All-zero sequences are retained. A known-alpha/lambda selection-aware likelihood is implemented only as a validation benchmark. No response-model context term or process innovation was introduced.

Before formal runs, 34 basic tests passed, including GH moments, conditional posterior parameters, all-missing sequences, lambda-zero likelihood constants, deterministic seeds, skip recursion, and analytic gradient/Hessian comparisons. Separate R likelihood and numerical optimization on one fixed smoke dataset per condition passed 24 estimate/SE comparisons for ignoring and including the known selection factor. A code-only type-stability improvement reduced one objective evaluation from about .147 s and 166 MiB of allocations to .00315 s and 361 KiB; nine exact value/gradient/Hessian equivalence checks passed. Scientific equations were unchanged.

Two execution corrections were made before the full confirmatory run and retained in validation history: worker arguments needed an argument vector; and the multistart selector originally picked a nonstationary fit by a 1e-12 objective-value difference even when other starts passed the original gradient criterion. Selection now prefers a stationary start within 1e-8 NLL of the lowest objective. This is a numerical objective-equivalence threshold, not a relaxation of the 1e-5 gradient requirement. The earlier benchmark outputs and freeze manifests remain preserved. The first 12 formal-seed datasets were used for this execution benchmark and are rerun consistently under the final code; no DGP or observation strength was tuned from these results.

The final four-worker benchmark ran 36 fits in approximately 14.2 s after worker setup (20.9 s including setup/compilation), with all fits valid. A serial checkpoint invocation retained all 36 files. The 3 x 1,000 full run uses four workers and one BLAS thread per worker, saves each replication atomically, and refuses checkpoints with a different code/design hash. Frozen source/configuration hashes are in config/frozen_run_manifest.toml. Subsequent 41-node checks cover the first ten replications per condition and the worst Hessian condition number per condition. Independent R formal refits use the first three per condition.

Failure classification and coverage denominators are not altered after looking at results. Conditional coverage uses valid fits only; unconditional coverage counts every failed fit as noncoverage. Paired contrasts use common replication IDs and report their own paired denominator and MCSE.
